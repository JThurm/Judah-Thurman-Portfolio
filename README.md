# Judah Thurman — Personal Portfolio

A personal portfolio website designed to showcase my software engineering projects, technical experience, creative work, and interests outside of programming.

The website combines a minimal dark interface with interactive animations, responsive layouts, and a visual gallery to create a portfolio that feels more like an interactive experience than a traditional resume.

---

## About

I'm an Electrical and Computer Engineering graduate from The University of Texas at Austin with a focus on software engineering, full-stack development, and system design.

This portfolio serves as a central place to showcase the projects I've worked on throughout my academic and professional development, as well as some of the creative work I enjoy outside of software.

## Website Structure

The portfolio is organized into several sections:

### Home

The landing page introduces who I am and provides navigation to the rest of the portfolio.

### About

A brief overview of my background, interests, and approach to software engineering.

### Services

Highlights the areas of software development and technical work that I am interested in.

### Portfolio

A collection of selected software engineering and technical projects.

Each project includes information about the technologies used, the problem being solved, and links to relevant repositories or demonstrations.

### Hobbies

A look at some of the creative work I enjoy outside of software engineering.

Current categories include:

- 3D Modeling
- Drawing
- Woodworking

### Gallery

Each hobby has its own dedicated gallery containing images and videos.

The gallery supports different media sizes, allowing projects and artwork to be presented in a more dynamic layout.
